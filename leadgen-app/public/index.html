Account Settings

My profile, daily lead cap, backup & restore, and your outreach signature

My profile

Update your own username and/or password. Requires your current password to confirm.

Daily lead cap

How many new leads you can hunt per day (default 300). This is per-account.

Signature

Appended to the end of every generated outreach message and every campaign email. Fully rich - bold/italic, links, images, and lists are all supported and will render as real formatting in sent emails.

Default AI providers

Which provider to pre-select for content generation and inspection - "Auto" tries Groq, then Gemini, then DeepSeek in order. You can still override this per-generation; this just sets the starting default.

Backup & restore

Download everything in your account - niches, catch logs, leads, saved API keys (every provider), business analysis results, generated outreach content, theme, daily cap, page size, and signature - as one file. Re-importing merges into whatever's already there: it never deletes or overwrites your existing records or anything fresher than the backup, only adds what's new. The download includes your API keys in plain text, so store the file somewhere private.
